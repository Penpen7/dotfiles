Use it from nix.conf

Add the cache to /etc/nix/nix.conf (or ~/.config/nix/nix.conf):

extra-substituters = https://nix.u-naoki.com
extra-trusted-public-keys = uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w=

Use it from a flake

Declare it in nixConfig and accept it with --accept-flake-config:

nixConfig = {
  extra-substituters = [ "https://nix.u-naoki.com" ];
  extra-trusted-public-keys = [
    "uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w="
  ];
};

Use it for a single command

nix build \
  --extra-substituters https://nix.u-naoki.com \
  --extra-trusted-public-keys uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w= \
  github:Penpen7/dotfiles#darwinConfigurations.personal.system

Non-root users can only add substituters that are listed in trusted-substituters, or when they are in trusted-users.

What is cached

The closures of darwinConfigurations.work.system and darwinConfigurations.personal.system for aarch64-darwin. Anything not built by those configurations will miss and fall back to your other substituters.
