⚙️ How to use it

Append to /etc/nix/nix.conf or ~/.config/nix/nix.conf:

extra-substituters = https://nix.u-naoki.com
extra-trusted-public-keys = uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w=

Declare it in nixConfig and run with --accept-flake-config:

nixConfig = {
  extra-substituters = [ "https://nix.u-naoki.com" ];
  extra-trusted-public-keys = [
    "uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w="
  ];
};

Just for this one build:

nix build \
  --extra-substituters https://nix.u-naoki.com \
  --extra-trusted-public-keys uehara-nix-cache:u+qjBIvib1P7LsoLQK6vVNTqryaG3cV6ai/u5trJQ2w= \
  github:Penpen7/dotfiles#darwinConfigurations.personal.system

💡 Non-root users can only add substituters listed in trusted-substituters, or if they are in trusted-users.
